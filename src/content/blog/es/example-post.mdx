### Un título más pequeño

Los bloques de código tienen resaltado de sintaxis y un botón para copiar:

```ts
// Saluda a alguien por su nombre.
function greet(name: string): string {
  return `Hola, ${name}!`;
}

console.log(greet("mundo"));
```

Una línea muy larga se desplaza dentro de su propio bloque:

